# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly.

**Do not open a public issue.**

For security concerns, please contact: **serkanbyx1@gmail.com**

We will respond as quickly as possible and work with you to resolve the issue.
